# Dratewka — The Shoemaker Game

A small browser-based text-adventure / map game built with plain JavaScript, HTML and CSS.

## Quick Start

- Open `index.html` in your browser.

## How to Play

Type commands into the input box (it auto-focuses on click or keypress), then press Enter.

- Movement: `N`, `S`, `E`, `W` or `NORTH`, `SOUTH`, `EAST`, `WEST`
- Take item: `TAKE <item>` or `T <item>`
- Drop item: `DROP <item>` or `D <item>`
- Use item: `USE <item>` or `U <item>`
- Vocabulary: `V` (shows helpful keywords)
- Gossips: `G` (flavor text)
